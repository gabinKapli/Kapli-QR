Comment ca fonctionne :

1) Le scanner s'ouvre dans un composant Web Embed Glide.
2) La camera detecte un QR code.
3) Le QR code doit contenir uniquement l'identifiant de la ligne produit.
4) Le scanner recupere l'URL de la page Glide qui contient le Web Embed.
5) Il garde automatiquement le debut de l'URL 
6) Il ajoute ensuite l'ecran de detail produit, puis l'identifiant scanne :
